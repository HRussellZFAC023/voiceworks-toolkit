# ASMR.one Ultimate

[asmr.one](https://asmr.one) のコミュニティ駆動型拡張スイート。[Tampermonkey](https://www.tampermonkey.net/) ユーザースクリプトとして動作し、ローカル AI 文字起こし、リアルタイム翻訳、セマンティック検索など 25 以上の機能を搭載して学習体験を強化します。

## 機能

### 言語学習

#### 学習モード — デュアル言語字幕
没入型学習向けのリアルタイム同期字幕。日本語を主行として表示し、英語訳をぼかし表示できます。LRC 歌詞の自動読み込みと Whisper ライブ文字起こしに対応。中国語字幕は Google Translate で自動的に日本語化され、学習の主表示を日本語で維持します。

#### ライブ文字起こし — オンデバイス音声認識
プレーヤーから上限付きのライブ音声を直接取得して文字起こしします。通常経路ではファイルのアップロードも大容量トラックの重複ダウンロードも行いません。[Transformers.js](https://huggingface.co/docs/transformers.js) の多言語 Whisper を専用 Worker で実行し、安定して利用できる場合は WebGPU、制約のある端末では小型の `whisper-tiny`/WASM 経路を使用します。ライブ取得が使えない場合はホストの低品質ストリームを先に試し、完全なストリームの互換デコードはホストが 32 MiB 以下と明示した場合だけ許可します。モデル読み込み・推論・ストリーム取得・デコードには停止しないための上限があります。結果はトラック単位でキャッシュ（90日 TTL）され、LRC/VTT、または未翻訳の日本語 TXT に書き出せます。

#### ニューラル翻訳 - Web 翻訳パイプライン
翻訳はリモート Web パイプライン（Google Translate エンドポイント）で処理し、ホストローテーション、リトライ/バックオフ、レート制限クールダウン、リクエスト重複排除、原文エコー検出、共有キャッシュを備えます。表示テキストは現在の英語・中国語・日本語 UI 言語を対象とし、日本語から中国語への翻訳にも対応します。

OpenAI 互換の翻訳エンドポイント・モデル・API キーを任意設定でき、失敗時は Google にフォールバックします。原文エコーを検出し、未翻訳の日本語文字起こしは TXT として個別保存できます。

#### 緊急プレイリストバックアップ
サイト障害時にも、自分のプレイリストとコミュニティ/公開プレイリストを混同しないよう別々に JSON・CSV・TXT へ保存します。最新 JSON はユーザースクリプトストレージにも保持されます。Google Drive には最小権限 `drive.file` で明示的に分けた2ファイルをアップロードできます。地域制限時は直結失敗後に東京の読み取り専用 API プロキシへフォールバックします。

#### インターフェース翻訳
中国語/日本語 UI 文字列を現在の英語・中国語・日本語ロケールに合わせて変換し、一般的な操作項目には高速な静的マップを使用します。

### 検索と発見

#### セマンティック検索 — AI 駆動の発見
キーワードの完全一致ではなく、意味による作品検索。Jina v3 埋め込み API でタイトルと説明をベクトル化し、ローカル IndexedDB に保存。多言語クエリとページネーション結果をサポート。

#### 高度な検索 — マルチフィルタークエリビルダー
タグ、サークル、声優、日付範囲、評価、価格によるフィルタリング。AND/OR ロジックによる複数条件の組み合わせ。検索履歴の保存に対応。

### 再生と没入

#### ラジオモード — 連続シャッフル再生
ライブラリ全体からのシャッフル連続再生。ランダムに作品を選択し、全トラックを順次再生。ヘルスチェックと自動リカバリー機構により途切れのない再生を実現。再生状態はページリフレッシュ後も保持。

#### プレイリストモード — 順次作品再生
プレーヤーバーに前進/後退ナビゲーションコントロールを注入したキュレーション再生。現在の作品が終了すると自動的に次の作品へ進行。プレイリスト発見パネルでコミュニティプレイリストを閲覧・検索・有効化。

#### シャッフル
ホストアプリのネイティブシャッフルコントロールと統合された拡張シャッフル機能。

#### オーディオキャッシュ — オフライン再生
オフライン再生と再訪時の帯域幅削減に使える、任意の IndexedDB 音声キャッシュです。プレーヤーのストリームとの重複を避けるため、全トラックのバックグラウンドダウンロードは既定で無効です。ローカル保存が必要な場合は設定で「オフライン音声キャッシュ」を有効にしてください。

### メディアとビジュアライゼーション

#### メディアビューア — インラインギャラリー
画像・動画を展開するライトボックス。常に見えるポインター操作と専用の開くボタンを備えます。画像は遅延取得して表示前に検証し、DLsite 画像は日本リレーを優先、Cloudflare の HTTP 200 制限プレースホルダーはコンテンツとして表示せずスキップします。JPG、PNG、GIF、WebP、MP4、WebM、MOV、PDF などに対応します。

#### プレーヤーギャラリー — アルバムアートブラウザ
プレーヤーのアルバムアート領域に統合された画像ギャラリー。高コントラストの矢印・開く操作、スワイプ、キーボードショートカット、隣接画像の遅延読み込みに対応します。

#### オーディオビジュアライザー — リアルタイムスペクトラム表示
Web Audio API の AnalyserNode を使用した 40 バー周波数ビジュアライゼーション。折りたたみ可能なコンパクトビューと拡張プレーヤー統合ビュー。

#### プレーヤーフルスクリーン
CSS ベースのプレーヤー領域フルスクリーン拡張。ショートカット：F。

### 進捗と整理

#### 自動進捗追跡
リスニング進捗を自動追跡。再生開始時に「リスニング中」、トラック 80% 完了時に「リスニング済み」にマーク。進捗チェックマークがサイト全体の作品カードに表示。

#### フォルダダイバー — スマートディレクトリナビゲーション
ネストされた作品ディレクトリ構造をインテリジェントにナビゲート。オーディオファイル数とコンテンツ関連性で重み付けするフォルダスコアリングアルゴリズムを使用。

#### フラットビュー — 代替ファイルブラウザ
作品の全ファイルをフラットリストで表示するサイドドロワーパネル。ダイレクト再生、ライトボックス画像表示、ファイルパスコピーに対応。

#### 作品ツリーコピー
作品のファイルパスとディレクトリ構造をフォーマット済みテキストとしてクリップボードにコピー。

### メタデータと情報

#### 作品メタデータパネル
サークル情報、声優クレジット、発売日など、デフォルト UI に表示されないフィールドを含む拡張メタデータ表示。

#### HVDB クロスリファレンス
作品ページに HVDB データベースへのワンクリックリンクを追加し、クロスデータベース検索を可能に。

#### コメントセクション
作品ページに注入されたコミュニティコメントセクション。localStorage バックアップの永続ストレージとリプレスレッドに対応。

### クオリティオブライフ

#### キーボードショートカット
ハンズフリー操作のための包括的なキーボードコントロール：Space/K（再生/一時停止）、矢印キー（シーク/音量）、括弧キー（速度）、数字キー（パーセントジャンプ）、M（ミュート）、F（フルスクリーン）、B（ぼかし切り替え）、J（日本語字幕切り替え）。

#### 無限スクロール
IntersectionObserver ベースの無限スクロールでページネーションを置換。ホーム、カテゴリ、検索ページに対応。

#### OS メディア統合
システムメディアコントロール（通知センター、ロック画面）に作品メタデータとアルバムアートを更新。OS メディアキーから再生コントロール。

#### ダイナミックファビコン
現在再生中の作品のカバーアートをブラウザタブのファビコンとして表示。

#### タグフィルター
任意のタグをクリックして即座にフィルタリング。ナビゲーション間で永続化するフィルターバー。

#### ルート状態同期
ビュー状態（フィルター、ソート順、検索クエリ）を URL クエリパラメーターと同期。ページリロード後も復元。

#### JOI ツール — インタラクティブエッジゲーム
Whisper リアルタイム文字起こしと統合されたインタラクティブエッジゲーム。音声コマンドを聴取し、設定可能な難易度に対応。

#### SFW モード — セーフフォーワーク
サイト全体の画像とサムネイルを非表示にし、公共の場での閲覧に対応。

#### 設定バックアップ — エクスポート/インポート
すべての設定と環境設定を JSON ファイルにエクスポート。新しいブラウザでインポートして設定を復元。

#### プレーヤー翻訳 — トラックタイトル翻訳
Web 翻訳パイプラインを使って、プレーヤー内の日本語・中国語トラックタイトルを現在の UI 言語へリアルタイム翻訳。

#### CJK タグ翻訳
UI 全体の CJK タグ（作品カード、検索、フィルター）を現在の UI 言語へ翻訳し、結果をキャッシュします。

#### CORS 修正
コンテンツ配信のクロスオリジン制限に対する透過的なプロキシ回避策。

#### 言語ゲートの自動復旧
ASMR.one が英語向けブロック画面を返した場合、ユーザースクリプトは中国語優先の特権リクエストで信頼済みフロントエンドを同じページ上に復旧し、検証済みの遅延ルート用アセットも先に読み込みます。後続の画面遷移で英語優先リクエストへ戻ることを防ぎ、実際のサイトオリジン、ログイン、ローカルストレージを維持します。Firefox 全体のウェブサイト言語設定は変更しません。

#### ローカライゼーション
完全な英語・中国語・日本語 UI ローカライゼーション。すべてのユーザー向け文字列は `I18n.t()` と `I18n.format()` による補間をサポート。

## インストール

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストール。
2. リポジトリをクローンして依存関係をインストール：
   ```bash
   git clone https://github.com/HRussellZFAC023/voiceworks-toolkit.git
   cd voiceworks-toolkit/asmr-one-ultimate
   npm install
   ```
3. **開発モード**：
   ```bash
   npm run dev
   ```
   `http://localhost:5173/asmr-one-ultimate.user.js` を開いてスクリプトをインストール。開発サーバーを起動したまま `https://asmr.one/` を閲覧。

4. **プロダクションビルド**：
   ```bash
   npm run build
   ```
   ブラウザで `dist/asmr-one-ultimate.user.js` を開き、Tampermonkey 経由でインストール。

## テスト

```bash
npm test                # Vitest ユニットテスト
npm run test:e2e        # Playwright E2E（ヘッドレス Chromium）
npm run test:e2e:headed # E2E ブラウザ表示あり
npm run test:e2e:ui     # Playwright UI モード
npm run test:e2e:debug  # ステップスルーデバッグ
```

テストはヘッドレス Chromium ブラウザで自動ユーザースクリプト注入により実行。手動のブラウザ設定や Tampermonkey インストールは不要。GM_* API は localStorage を使用してスタブ化。

## アーキテクチャ

**ユーザースクリプト注入** — ホストサイトの Vue 2.6 + Quasar フレームワークに `KikoeruBridge` シングルトン経由でフック。アプリの Vuex ストア、Vue Router、Axios HTTP クライアントを公開。機能モジュールは独立モジュールとしてマウントされ、中央ライフサイクルに登録。

```
src/
├── features/          機能モジュール（30 以上の独立機能）
│   ├── components/    FeatureController 経由でマウントされる Vue 3 SFC
│   ├── radio/         ラジオモードサブシステム
│   ├── playlist/      プレイリストモードサブシステム
│   ├── media/         メディアビューアサブシステム
│   └── settings/      設定パネルとコントロール
├── services/          TranslationService、WorkService、DLsiteService
├── infrastructure/    KikoeruBridge、AudioCache、HttpClient、StorageManager
├── core/              Config、Utils、Cache、EventBus、Logger、CentralObserver
├── store/             AppStore（リアクティブ状態）、ConfigStore
├── api/               REST API クライアント（Auth、Work、Playlist、History 等）
├── ui/                共有 UI コンポーネントとヘルパー
├── composables/       Vue 3 コンポーザブル（再利用可能なリアクティブロジック）
├── scrapers/          DLsite および外部サイトスクレイパー
├── styles/            CSS 変数、コンポーネントスタイル、レイアウト修正
└── types/             TypeScript 型定義
```

### 主要な技術パターン

- **CentralObserver** — `document.body` 上の単一 MutationObserver。機能モジュールがコールバックを登録して効率的に DOM を監視
- **Web Workers** - Whisper 文字起こしをメインスレッド外で実行し、UI 応答性を維持
- **WebGPU + WASM** - Whisper は WebGPU 優先、埋め込みモデルは端末能力に応じて WASM へフォールバック
- **リモート翻訳パイプライン** - ホストローテーション、リトライ/バックオフ、レート制限クールダウン、キャンセル可能タスク、共有キャッシュで再生中やシーク時の翻訳を安定化
- **IndexedDB** — `idb` ライブラリによるベクトル埋め込み、オーディオキャッシュ、文字起こしストレージ
- **GM Storage** — Tampermonkey の `GM_getValue`/`GM_setValue` によるユーザー設定の永続化
