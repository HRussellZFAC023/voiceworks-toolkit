🎵 Voiceworks Toolkit - All-in-One Enhancement Suite for ASMR.one

30+ features for browsing, studying, and listening. Voiceworks blends on-device AI with web-assisted services, then caches results locally so the experience stays fast.

📚 Language Learning

  • Learner Mode: Real-time dual-language subtitles. Japanese stays on top with furigana, and English can stay blurred until you hover or press B. Karaoke-style highlighting follows the spoken line as audio plays.
  • Live Transcription: On-device Whisper speech-to-text. Turn any track into study material directly from the player with no manual uploads. WebGPU acceleration is used when available, with WASM fallback. Transcripts are cached for 90 days and can be exported as LRC, VTT, or SRT.
  • Neural Translation: Web translation pipeline for JA/CN to EN with retry logic, host rotation, and shared caching. Subtitles, tags, titles, and key UI text are translated in real time.
  • Interface Translation: Translates core Chinese and Japanese interface text to English, including menus, sort options, and dynamic labels.
  • JPDB Integration: Vocabulary mining via jpdb.io. Look up words from subtitles and keep your Japanese study progress in one flow.

🔍 Search & Discovery

  • Semantic Search: Find works by meaning, not just keywords. Uses Jina embeddings with vectors cached in IndexedDB for faster repeat queries. Supports multilingual search, including English queries for Japanese content.
  • Advanced Search: Multi-filter query builder with tag include/exclude, circle, voice actor, date range, rating, and price filters. Supports AND/OR logic with saved search history.

📻 Playback

  • Radio Mode: Continuous shuffled playback across your library for long listening sessions, with auto-recovery after interruptions. Session state persists across refreshes.
  • Playlist Mode: Sequential playback with forward/back navigation. Browse and activate community playlists from the Playlist Discovery panel.
  • Audio Cache: IndexedDB-backed track caching for faster replays and offline playback.
  • Enhanced Shuffle: Improved shuffle behavior that keeps your current track and remembers shuffle state between sessions.

🎬 Media & Visualization

  • Media Viewer: Click-to-expand lightbox for images, videos, and PDFs bundled with works. Includes slideshow mode, keyboard navigation, and touch swipe support.
  • Player Gallery: Album art slideshow built into the player, with arrow controls and keyboard shortcuts.
  • Audio Visualizer: 40-bar real-time frequency spectrum powered by the Web Audio API, with compact and expanded layouts.
  • Player Fullscreen: Fullscreen expansion for the player area. Press F to toggle.

📊 Progress & Organization

  • Auto Progress Tracking: Marks works as "listening" when playback starts and "listened" at 80% completion. Progress appears on cards throughout the site.
  • Folder Diver: Smart directory navigation that finds playable audio inside nested folder structures.
  • Flat View: Side drawer that lists all files in a flat layout, with direct playback and lightbox image viewing.

⚙️ Quality of Life

  • Infinite Scroll: Replaces pagination on home, category, and search pages.
  • OS Media Integration: System media controls (notification center, lock screen) show track metadata and cover art.
  • Translated Tags: CJK tags are translated to English across the UI with local IndexedDB caching.
  • SFW Mode: Content filtering for public or shared environments.
  • Settings Backup/Restore: Full settings export and import.
  • Localized Settings: UI available in English, 中文, and 日本語.

🛠️ Technical Details
  • Runs as a Tampermonkey/Violentmonkey userscript, so no standalone app is required
  • Whisper transcription runs in dedicated Web Workers with WebGPU acceleration and WASM fallback
  • Translation and semantic embedding requests use web APIs with retry/backoff and local caching
  • Transcripts, translations, vectors, and media cache are stored locally in IndexedDB
  • Built with TypeScript, Vue 3, Vite, and Transformers.js
