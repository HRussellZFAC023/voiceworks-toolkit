🎵 Voiceworks Toolkit — All-in-One Enhancement Suite for ASMR.one

30+ features for browsing, studying, and listening — powered by on-device AI that runs entirely in your browser. No data ever leaves your machine.

📚 Language Learning

  • Learner Mode — Real-time dual-language subtitles. Japanese as the primary line with furigana annotations, blurrable English translations underneath. Hover or press B to reveal. Includes karaoke-style word highlighting that tracks speech in real time.
  • Live Transcription — On-device Whisper speech-to-text. Turns any audio into study material directly from the player — no file uploads needed. WebGPU accelerated with WASM fallback. Transcripts are cached for 90 days. Supports Japanese, English, Chinese, Korean, and more. Export to LRC, VTT, or SRT.
  • Neural Translation — Local JA→EN machine translation running entirely in-browser via Web Workers. Chinese text falls back to Google Translate. Translates subtitles, tags, titles, and UI elements in real time with shared caching.
  • Interface Translation — Localizes the entire platform UI to English: menus, buttons, sort options, and dynamic text.
  • JPDB Integration — Vocabulary mining via jpdb.io. Look up words from subtitles and track your Japanese vocabulary progress.

🔍 Search & Discovery

  • Semantic Search — Find works by meaning, not just keywords. Uses AI embeddings stored locally in IndexedDB. Supports multilingual queries — search in English, get Japanese results.
  • Advanced Search — Multi-filter query builder with tag include/exclude, circle, voice actor, date range, rating, and price filters. AND/OR logic with saved search history.

📻 Playback

  • Radio Mode — Continuous shuffled playback across your library for extended listening sessions. Auto-recovery through network interruptions. State persists across page refreshes.
  • Playlist Mode — Sequential playback with forward/back navigation. Browse and activate community-curated playlists via the Playlist Discovery panel.
  • Audio Cache — Offline playback via IndexedDB caching. Tracks are cached during playback for instant replay on revisit.
  • Enhanced Shuffle — Improved playlist shuffle that maintains the current track and persists across sessions.

🎬 Media & Visualization

  • Media Viewer — Click-to-expand lightbox for images, videos, and PDFs bundled with works. Slideshow mode, keyboard navigation, swipe support on touch devices.
  • Player Gallery — Album art slideshow integrated into the player with arrow controls and keyboard shortcuts.
  • Audio Visualizer — 40-bar real-time frequency spectrum using the Web Audio API. Compact and expanded views with smooth animations.
  • Player Fullscreen — Fullscreen expansion for the player area. Press F to toggle.

📊 Progress & Organization

  • Auto Progress Tracking — Automatically marks works as "listening" when playback starts and "listened" at 80% completion. Progress appears on work cards throughout the site.
  • Folder Diver — Smart directory navigation that automatically finds audio content in nested folder structures.
  • Flat View — Side drawer showing all files in a flat list with direct playback and lightbox image viewing.

⚙️ Quality of Life

  • Infinite Scroll — Replaces pagination on home, category, and search pages.
  • OS Media Integration — System media controls (notification center, lock screen) show track metadata and album art.
  • Translated Tags — All CJK tags translated to English across the entire UI with IndexedDB caching.
  • SFW Mode — Content filtering for public environments.
  • Settings Backup/Restore — Full configuration export and import.
  • Localized Settings — Complete UI in English, 中文, and 日本語.

🛠️ Technical Details
  • Runs as a Tampermonkey/Violentmonkey userscript — no browser extension needed
  • AI models (Whisper, translation) run in dedicated Web Workers with WebGPU acceleration and automatic WASM fallback
  • All AI processing is on-device — no data is sent to external servers (except Google Translate for Chinese→English)
  • Caches transcripts, translations, and embeddings locally in IndexedDB
  • Built with TypeScript, Vue 3, Vite, and Transformers.js
